What you need

  • uv sync and npm install done, so npm test runs.
  • The current commit deployed to staging: npm run deploy:staging.
  • Wrangler logged in to the account that owns truuehsoft.com, for wrangler tail and secret list.
  • KNOWN_PLAYER_ID: a Discord ID that has ranked matches on the 1v1 leaderboard.
  • UNRANKED_ID: a valid Discord ID with no ranked data, e.g. a fresh alt account.
  • STREAK_PLAYER_ID (optional): a player currently on 10+ wins in a row.
  • IN_MATCH_ID (optional): a player in a ranked match (with an opponent) right now.
  • .dev.vars.prod holding real SLUGBOT_API_KEY and DISCORD_BOT_TOKEN for the first prod deploy.

Watching logs

Run this in a second terminal while you test staging. Each request prints one event, and its logs array holds the JSON lines the Worker wrote.

npx wrangler tail --env staging --format json

Staging logs at DEBUG and caches Discord names for 60 s. Prod logs at INFO and caches for 18000 s (5 h).

Unit-level harness: how to build the fake scenarios yourself

Scenarios tagged unit drive the real handlers with the fakes from tests/, so you can force upstream failures that can't be produced on demand against real Slugbot or Discord. Start a shell from the repo root with uv run python and paste this:

import asyncio, json, logging
import tests  # puts src/ on sys.path
from tests.test_handlers import FakeSlugbot, FakeDiscord, _match, _page, _wins, PLAYER_ID, OPPONENT_ID
from tests.slugbot.test_dtos import PLAYER_JSON, MATCH_BATCH_JSON
from tests.discord.test_dtos import USER_JSON
from tests.test_config import make_env
from tests.fakes import MemoryCache
from api import handlers
from api.config import Settings
from api.context import Context
from api.slugbot import SlugbotClient
from api.discord import DiscordClient
from api.log import JsonFormatter

h = logging.StreamHandler(); h.setFormatter(JsonFormatter())
logging.getLogger().handlers[:] = [h]; logging.getLogger().setLevel("DEBUG")
logging.getLogger("asyncio").setLevel("WARNING")

def call(slugbot, discord=None, cache=None, player_id=PLAYER_ID, **env):
    s = Settings.from_env(make_env(**env))
    ctx = Context(s, SlugbotClient(s, slugbot), DiscordClient(s, discord or FakeDiscord()),
                  cache if cache is not None else MemoryCache())
    r = asyncio.run(handlers.get_player_details(ctx, {"player_id": player_id}))
    print(r.status, r.all_headers()); print(json.dumps(json.loads(r.render()), indent=2))
    return r

_match(ts, won) builds a 1v1 between PLAYER_ID (team 0) and OPPONENT_ID (team 1). _page(matches, next_cursor) builds a batch page. FakeSlugbot(player=(status, body), batches={cursor: (status, body)}, error=exc). FakeDiscord(users={id: (status, body) or exc}). MemoryCache(entries={...}, error=exc).

Scenarios that go through the Worker entrypoint (config errors, access log, unhandled errors) also need fake workers and js modules, because src/entry.py imports them. Paste this after the block above:

import sys, types
class Response:
    def __init__(self, body, status=200, headers=None):
        self.body, self.status, self.headers = body, status, headers or {}
        self.js_object = self
class WorkerEntrypoint:
    def __init__(self, env): self.env = env
async def _no_fetch(*a, **k): raise RuntimeError("no network in harness")
class _NoCaches:
    async def open(self, name): raise RuntimeError("no cache in harness")
sys.modules["workers"] = types.SimpleNamespace(Response=Response, WorkerEntrypoint=WorkerEntrypoint, fetch=_no_fetch)
sys.modules["js"] = types.SimpleNamespace(caches=_NoCaches())
import tests, entry
from api import config
from tests.test_config import make_env

class Req:
    def __init__(self, method, path, headers=None):
        self.method, self.url = method, "https://qa.local" + path
        self.headers = headers if headers is not None else {"user-agent": "qa-harness", "cf-ray": "qa-ray"}
        self.cf = types.SimpleNamespace(country="IL", asn=12345, asOrganization="QA Net")

def run(method, path, **env):
    config._cached_settings = None  # settings are cached per isolate; reset between runs
    r = asyncio.run(entry.Default(make_env(**env)).fetch(Req(method, path)))
    print(r.status, r.headers, r.body)
    return r

Pass NAME=None to make_env to remove a variable.
